# Code of Conduct

Voxta follows the Contributor Covenant Code of Conduct.

## Our Pledge

We pledge to make participation in this project respectful and harassment-free for everyone.

## Expected Behavior

- Be respectful and constructive.
- Focus criticism on code and behavior.
- Assume good intent, but accept responsibility for impact.

## Unacceptable Behavior

- Harassment, threats, or discrimination.
- Publishing private information without consent.
- Sustained disruption of project work.

## Enforcement

Maintainers may remove comments, close issues, block users, or take other reasonable actions to protect the project community.
